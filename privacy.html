Privacy policy

LevKoll · last updated 9 October 2026

LevKoll is a personal, non-commercial Android app that tracks online orders by reading order and shipping emails in the user's Gmail account. This page describes what it reads, where that goes, and what is kept.

What LevKoll accesses

With your permission, LevKoll uses the Gmail read-only scope (gmail.readonly). It cannot send, delete, or change email.

The app searches for recent emails that look like order confirmations, payment notices, or shipping and delivery notices. For each match it first reads only the sender and subject line. Emails that are clearly not about an order are skipped on the phone without being opened.

How it is processed

For an email that may concern an order, the app sends its sender, subject, date and text over an encrypted, private network connection to a server run by the developer. That server passes the email to Anthropic's Claude API, which extracts the order details — shop, order number, items, tracking number and delivery dates — and returns them to the phone.

The server does not store the email. Anthropic processes it under its commercial API terms, which do not permit using it to train models.

What is stored, and where

  • On your phone: the orders the app has found, kept in the app's private storage. This data is excluded from Android's automatic cloud backup. You can export a backup file yourself; where you keep it is up to you.
  • On the server: a technical log of each request — for example the shop name and order number found, and whether it matched an existing order — kept for troubleshooting and removed automatically as the log rotates. The log does not contain email subjects, sender addresses, or email text.

Sharing

Your data is not sold, not shared with anyone other than the processing step described above, and not used for advertising.

Google API Services User Data Policy

LevKoll's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

  • Disconnect Gmail in the app's settings, or revoke access at myaccount.google.com/permissions.
  • Uninstalling the app deletes everything it stored on the phone.
